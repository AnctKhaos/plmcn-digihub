# CN Digital Hub — Green Edition

A concise green-and-white React/Vite prototype for the **College of Nursing Digital Hub**.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## Notes

This is a front-end prototype. For official deployment, connect announcements, resources, locker records, and student concerns to Firebase, Supabase, Laravel/PHP + MySQL, or a PLM-managed server.
